📌 Project Overview
The IPL Auction Performance Dashboard provides comprehensive insights into player valuations, franchise bidding behavior, and purse utilization across IPL auction seasons. Built using Power BI, it transforms raw auction data into clear, actionable visual analytics to track spending efficiency, overseas quota distribution, and marquee acquisitions.

📊 Key Features & Analysis

Purse Utilization & Budget Distribution: Track total funds spent versus remaining purse across all IPL franchises.

Role-Based Investment Breakdown: Analyze expenditures across Batsmen, Bowlers, All-rounders, and Wicketkeepers.

Top Sold Players & Marquee Buys: Identify the highest-paid domestic and international acquisitions per auction.

Overseas vs. Indian Player Allocation: Compare slot distribution, price tags, and percentage share of squad spend.

Interactive Multi-Level Filtering: Slicers for Teams, Player Roles, Base Price brackets, Auction Year, and Nationalities.

🛠️ Tech Stack & Tools
Business Intelligence: Microsoft Power BI Desktop

Data Modeling & Calculations: DAX (Data Analysis Expressions)

Data Transformation & Cleaning: Power Query (M Language)

Asset Design & Layout: Custom landing page canvases and graphic assets

📐 Dashboard Architecture
├── Data Model/
│   ├── Auction Raw Data (Player stats, bids, teams, categories)
│   ├── Dimension Tables (Teams, Player Roles, Seasons, Countries)
│   └── Measures Table (Total Spend, Player Count, Average Bid, Overseas Ratio)
├── Visuals & Views/
│   ├── Landing Page / Overview (KPI cards & team purse summaries)
│   ├── Team Performance & Squad Composition View
│   └── Player Valuation & Role Analysis View
└── Design Assets/
    └── Custom Backgrounds & Icons (Optimized for dark/light themes)
